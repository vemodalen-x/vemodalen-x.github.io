# Photography Mentor v1.2.0

Photography Mentor v1.2.0 is the first standalone commercial distribution of the browser-local photography learning application.

## Highlights

- 62 traceable knowledge cards organized into 7 stages and 22 learning nodes.
- Four focused workspaces for daily learning, concept mapping, practice and retrieval.
- Local photo diagnostics, Before/After evidence, learning plans and spaced review.
- User-controlled SYBJ workflow with official WeChat login handoff and local summary import.
- Full local-data export, validated restore and one-step deletion.
- Installable PWA with no runtime CDN, account server, analytics SDK or photo upload.
- Commercial documentation, third-party notices, deterministic checksums and automated public-release auditing.

## Sanitization

The attached archive was built from an explicit allowlist. It contains no screenshots, raster photos, local book inventory, private documents, credentials, machine-specific paths or prior repository history. The only image asset is the product's vector application icon.
