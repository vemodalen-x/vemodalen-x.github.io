# Photography Mentor v1.3.0

Photography Mentor v1.3.0 turns the standalone browser-local product into one evidence-aware learning system instead of a collection of separate tools.

## Highlights

- 74 traceable knowledge cards organized into 7 stages and 22 learning nodes, including 12 sanitized topic summaries from the local photography library.
- One Mentor Core for coaching, photo diagnostics, retrieval and daily learning sessions.
- Inspectable decisions with facts, assumptions, unknowns, one bottleneck, citations, one-variable practice and verification criteria.
- Four focused workspaces for daily learning, concept mapping, practice and retrieval.
- Local photo diagnostics, Before/After evidence, learning plans and spaced review.
- User-controlled SYBJ workflow with official WeChat login handoff and local summary import.
- Full local-data export, validated restore and one-step deletion.
- Browser-local accepted, rejected and verified advice feedback with user-written result evidence.
- Installable PWA with no runtime CDN, account server, analytics SDK or photo upload.
- A 14-case retrieval evaluation suite, core unit tests, browser regressions, deterministic checksums and automated public-release auditing.

## Sanitization

The attached archive was built from an explicit allowlist. It contains no screenshots, raster photos, local book inventory, private documents, credentials, machine-specific paths or prior repository history. The only image asset is the product's vector application icon.
