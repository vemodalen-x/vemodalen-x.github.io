# 隐私说明

生效日期：2026-09-07

Photography Mentor v1.3.0 是本地优先的静态 Web 应用。本发行包没有应用服务器、账号系统、广告 SDK 或分析 SDK。

## 本地保存的数据

应用可以在当前浏览器的 `localStorage` 中保存学习档案、草稿、学习计划、掌握度、练习日志、工作区状态、建议采纳或验证反馈，以及用户手动导入的 SYBJ 课程摘要。这些数据不会由本发行包自动上传。

照片像素在浏览器内存中处理，用于生成可解释的统计指标和 Before/After 预览。照片本身不会写入 `localStorage`，刷新或关闭页面后需要重新选择。

公开知识库包含本机摄影资料的主题级总结和聚合数量，不包含书籍文件名、文件路径、私人清单或原文。用户在应用中导入的笔记仍只保存在当前浏览器。

## 外部链接

来源链接和 SYBJ 微信登录会打开第三方网站。第三方网站可能独立收集登录、设备或访问数据，并适用其自己的隐私政策。Photography Mentor 不会读取第三方 Cookie、微信凭据或登录后的页面内容。

## 删除数据

用户可以在“资料库 → 数据与隐私”中导出完整学习备份、恢复备份或删除本产品写入的全部本地数据，也可以清除该站点的浏览器存储。卸载 PWA 不一定自动清除站点数据，需按浏览器设置处理。

## 部署方责任

自行部署者如果加入账号、分析、云存储、支付或模型 API，应在上线前更新本说明，明确数据控制者、处理目的、保存期限、跨境传输、用户权利和联系渠道。
