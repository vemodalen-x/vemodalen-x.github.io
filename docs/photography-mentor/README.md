# Photography Mentor

Photography Mentor 是一个本地优先的摄影学习与商业交付 Web 应用。它把计算摄影、摄影美学、前期拍摄、后期处理、评片方法和投稿前检查整理成可追溯知识卡，并用主动回忆、刻意练习、作品证据、间隔复习和本地素材预筛形成工作闭环。

## 产品能力

- 74 张可追溯知识卡：62 张公开来源摘要卡与 12 张脱敏本机资料主题总结。
- 第一性原理决策单：事实、假设、未知项、唯一瓶颈、来源、单变量行动与验证标准。
- Focus、Map、Studio、Library 四个任务空间。
- 知识图谱搜索、掌握度过滤、节点检查器和一键开课。
- 浏览器内照片亮度、对比度、饱和度、清晰度、高光和阴影诊断。
- 多张照片/文件夹的本地商业素材预筛：分辨率、文件体积、清晰度、曝光、人物/品牌/物业人工核查、平台适配和 CSV/JSON 元数据包。
- Adobe Stock、Shutterstock、Alamy、Wirestock、500px 官方入口 handoff；不自动上传、不读取账号凭据，EyeEm 只作待确认项。
- Before/After 练习证据、练习日志、学习档案和复习队列。
- 建议采纳、拒绝和结果验证反馈，随学习备份一并由用户控制。
- SYBJ 官方微信登录跳转，以及用户自有课程摘要的本地导入。
- 学习档案、计划、掌握度、练习和摘要的一键导出、恢复与删除。
- 无服务器账号、无广告追踪、无运行时 CDN，支持安装与离线使用。

## 启动

需要通过 HTTP 提供页面，不能直接双击 HTML 使用 Service Worker。

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8000/`。

## 验证

```powershell
npm test
```

`npm test` 会验证知识卡、分类结构、第一性原理决策契约、14 类检索评测、页面引用、离线缓存和公开发行边界。重新生成发行清单使用 `npm run manifest`；启动本地 HTTP 服务后可运行 `npm run test:browser` 做桌面与移动端回归。

## 数据边界

用户档案、草稿、复习状态、练习日志、决策反馈和手动导入摘要只保存在当前浏览器。照片像素与商业筛选缩略图只在当前标签页内处理，不写入浏览器持久存储；用户主动下载的 CSV/JSON 交付包只包含文件名、元数据和派生指标。应用不会读取微信凭据、Cookie 或登录后的 SYBJ 页面。

公开包不包含本机书籍清单、文件路径、私人资料、访问受限内容、凭据、截图或旧仓库历史。本机资料只发布主题级总结与聚合统计；知识库只保存摘要和来源链接，不重新发布教程或书籍全文。

本版本是可独立部署的静态单用户产品。支付、订阅、云同步、团队空间、服务端多模态模型和第三方自动上传 API 不在本发行包内；接入这些能力时必须另行完成账号安全、数据处理协议、计费、平台授权和运营合规。
