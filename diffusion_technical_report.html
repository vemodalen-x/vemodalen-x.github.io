摘要

源页的主线不是介绍一个孤立模型，而是把扩散生成的“概率建模 → 反向求解 → 条件控制 → 潜空间压缩 → 骨干替换 → 多模态应用 → 代码实现”串成一张学习图谱。

核心抽象

把数据分布连接到简单噪声分布，再学习从噪声回到数据的反向动力学。

三条优化轴

训练目标、采样求解器、表示空间共同决定质量、速度、显存和可控性。

七类应用

图像、视频、音频、3D、文本到图像、文本到视频和图像编辑。

工程结论：分析扩散系统时，先拆成 数据/表示空间、训练参数化、条件与 guidance、采样器/NFE、部署约束 五层，再讨论 U-Net 还是 Transformer。

2. 统一技术框架

页面将 DDPM、Score-based Diffusion、ODE Sampling、Flow Matching、Stochastic Interpolants 和 Consistency Models 并置。理解它们的共同接口，比记住每个名称更重要：给定一条从噪声到数据的路径，训练一个近似局部信息的网络，再通过数值求解生成样本。

数据x₀ ~ p_data
图像、视频、音频或 3D 表示
加噪/插值x_t
前向扩散、连续路径或离散状态
网络预测εθ / sθ / vθ
噪声、score 或速度场
条件控制文本、类别、图像、参考特征与 guidance
求解采样ODE/SDE、DDIM、DPM、Consistency 少步推理

2.1 DDPM：离散时间基线

前向过程逐步注入高斯噪声，使 x₀ 接近纯噪声 x_T；反向过程学习从 x_T 逐步恢复 x₀。常见训练形式是根据 x_t 和时间步预测噪声。

q(x_t | x_{t-1}) = N(sqrt(1-β_t) x_{t-1}, β_t I)
x_t = sqrt(ᾱ_t) x₀ + sqrt(1-ᾱ_t) ε
ε ~ N(0, I)

这是用于串联页面内容的标准表达；损失权重、参数化和 noise schedule 应结合论文与实现确认。

2.2 Score、SDE 与 ODE

Score 建模关注 ∇x log p_t(x)。Score-SDE 将离散扩散推广为连续时间 SDE，并对应 probability flow ODE，采样因此可以视作数值求解器问题。

工程上，网络负责估计局部方向，采样器负责以多少步、怎样的误差控制把方向积分成样本。

2.3 Flow Matching 与 Rectified Flow

Flow Matching 直接学习从简单分布到目标分布的速度场，使用条件路径训练，避免传统 normalizing flow 对 Jacobian determinant 的显式计算。Rectified Flow 强调更直的传输路径，目标是减少求解器工作量并提升少步生成的可行性。

2.4 Stochastic Interpolants

页面在理论基础和编程实践中都列出这一条目，但可见正文较少。可把它放在统一路径建模框架下理解：构造连接两个端点分布的随机插值，并学习相应的漂移/score 信息。

具体参数化与训练公式需进一步阅读原始资料确认。

4. 全局知识地图

A. 概率生成与路径建模

问题：如何把复杂数据分布转化为可学习、可采样的动力学过程？

技术：Diffusion Probabilistic Models、DDPM、Score Matching、Score SDE、Flow Matching、Stochastic Interpolants。

价值：定位训练目标、noise schedule、速度场和求解器误差。

B. 采样与推理加速

问题：如何用更少网络调用生成同等质量的样本？

技术：ODE、DDIM、DPM、Consistency、Improved/Simplified Consistency、Shortcut Models。

价值：直接决定线上 latency、吞吐、显存和成本。

C. 表示空间与潜扩散

技术：连续 VAE、VQ-VAE、VAE 优化、Stable Diffusion latent diffusion。

关系：把高分辨率算力瓶颈转化为编码器/解码器和潜空间质量问题。

D. 骨干与条件注入

技术：U-Net、Transformer/DiT、Mamba、Transformer U-Net、时间步/条件嵌入、Classifier/Classifier-Free Guidance。

价值：影响表示能力、算力曲线、条件遵循与模型扩展。

E. 多模态生成应用

技术：图像、视频、音频、3D、文本到图像、文本到视频、图像编辑。

关系：依赖潜空间、骨干、条件对齐和采样器；视频/3D 还要面对时空/多视角一致性。

F. 相邻范式与生成系统

技术：Normalizing Flow、VAE、Auto-regressive、Agent、Discrete-State、Multi-modal、GAN。

价值：根据时延、可控性和数据类型选择范式，而不是所有任务都使用扩散。

5. 分主题技术梳理

5.1 理论基础：离散噪声、score 与连续路径

页面按“早期 Diffusion → DDPM → Score Matching → Score SDE → Flow Matching → Stochastic Interpolants”排列，可用三种问题复习：概率转移、密度梯度、速度场。它们不应被当成互不相关的模型家族；关键差异在训练路径、目标参数化和数值积分方式。

源页：理论基础　源页：Flow Matching
5.2 采样方法：显式管理质量-速度权衡

ODE、DDIM 和 DPM 都回答：网络在给定时间步返回局部预测后，如何选择时间离散、步长和更新公式。生产评估至少记录 NFE、端到端延迟、显存峰值、吞吐、质量、条件遵循和失败率。

  • ODE：建立连续时间和数值积分直觉。
  • DDIM：提供与训练目标兼容的非马尔可夫加速路径。
  • DPM：利用扩散结构设计专用高阶求解器。
源页：采样方法
5.3 VAE 与 Stable Diffusion：像素空间到潜空间

典型链路为：

image --encode--> latent z --diffusion denoise--> z* --decode--> image*
  • VAE 决定潜空间保留纹理、边缘和颜色的能力。
  • 扩散在低分辨率潜空间运行，降低高分辨率计算量。
  • 文本条件经过编码器，再通过 cross-attention 等方式影响去噪网络。

VAE 不是无损前处理，压缩比、重建目标、数值范围和解码器都会成为质量瓶颈。

Stable Diffusion　VAE 相关优化
5.4 一致性与 Shortcut：少步生成

Consistency Models 试图让同一轨迹上不同噪声等级的状态映射到一致的干净结果，从而把多步推理压缩为少步甚至一步。页面还列出 Improved/Simplified Consistency Models 与 Shortcut Models。

重点不是简单减少循环次数，而是改变训练约束；质量、稳定性、蒸馏数据和条件控制会耦合。

Consistency Models　Shortcut Models

5.6 Guidance：把条件遵循变成可调旋钮
  • Classifier Guidance：需要额外分类器提供梯度信号，会增加模型和分布适配成本。
  • Classifier-Free Guidance：同一生成网络学习有条件和无条件预测，再在采样时组合；scale 会牵动多样性、过饱和和 prompt 遵循。

guidance scale 不应越大越好，应按条件遵循、质量、异常率和多样性做网格实验。

6. 面向工程实践的启发

6.1 优先级

  1. 先掌握 latent diffusion + CFG + DDIM/DPM 端到端链路。
  2. 再学习 VAE、噪声参数化和 sampler，解释换采样器后质量/速度变化。
  3. 然后进入 Flow Matching/Rectified Flow 和 Consistency，理解少步生成。
  4. 按项目需要深入 DiT、视频、3D、音频或 Mamba。

6.2 对 production model design 的直接价值

  • 潜空间：先压缩再扩散，易满足分辨率和成本约束。
  • 采样器解耦：训练模型与推理 solver 分层，便于切换质量档位。
  • 条件接口：把 prompt、类别、参考图、mask、Control signal 显式化。
  • 评测闭环：质量、条件遵循、多样性、延迟、显存、失败率共同决定可用性。

6.3 偏研究型内容

早期 Diffusion、Score-SDE、Stochastic Interpolants、Flow Matching/Rectified Flow 的路径设计，以及 Consistency/Shortcut 的少步约束，更适合训练问题抽象、目标函数设计和实验方法。

6.4 常见误区

  • 只记住加噪/去噪，忽略 score、ODE、速度场和 solver。
  • 只看 FID/CLIP，忽略条件遵循、重复率、安全、延迟和成本。
  • 把 VAE 当成无关紧要的编解码器，忽略压缩伪影和数值范围。
  • 把 guidance scale、采样步数当固定常数，不按场景分层。

建议的系统拆解

Input condition
  └─ text/image/mask encoder
      └─ condition embeddings
          └─ denoiser: U-Net or DiT
              └─ parameterization: epsilon / v / score / velocity
                  └─ sampler: ODE / DDIM / DPM / consistency
                      └─ VAE decoder or modality-specific decoder
                          └─ post-process + safety + evaluation

7. 可执行实验项目

项目 A：小型 DDPM

目标：在 MNIST/CIFAR-10 实现前向加噪、时间步嵌入、噪声预测和反向采样。

对照：β schedule、采样步数、epsilon/v 预测、U-Net 通道数。

产出：训练曲线、固定 seed 样本、不同步数网格、失败案例。

项目 B：DDIM/DPM 采样对比

固定 checkpoint，只更换采样器和步数，记录 NFE、延迟、显存、质量、条件遵循，画出速度-质量 Pareto 曲线。

项目 C：像素扩散 vs 潜扩散

用简单自编码器建立 latent，再在 latent 上训练扩散模型，对照压缩倍率、重建误差、吞吐、纹理和 VAE 伪影。

项目 D：Flow Matching / Rectified Flow

在二维 toy distribution 或小图像数据上学习速度场，对照路径曲率、训练稳定性、ODE 步数和样本质量。
