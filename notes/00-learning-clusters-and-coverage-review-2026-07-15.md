# 全库学习聚类与覆盖 Review：从 15830 条资源到八条个人学习路径

## 结论先行

**当前资源并没有全部完成语义学习。** 已经完成的是全库可发现性、核心方法归并和若干高价值来源精读；仍未完成的是 TIANYU2FM 全量视频、小红书正文、WaytoAGI 13,842 个节点正文、Latent.Space 其余 49 项、Karpathy 全视频逐段、全机 1,405 项正文以及多个课程/仓库的实践验收。

本轮做了三件更可靠的事：

1. **完整盘点**：57 篇当前笔记、164 张方法卡，以及 WaytoAGI、Latent.Space、MIT Bunny、Dwarkesh、小红书和旧本机库目录均进入统一账本。

3. **重新聚类**：不再按网站或文件夹顺序学习，而是按八类个人问题进入，目录层只在需要时下钻。

## “学完”的五道验收门

一个来源只有同时通过以下五门，才能称为“学习完毕”：

| 门 | 验收问题 | 证据 |
| --- | --- | --- |
| 1 发现完整 | 是否知道总量、目录、缺失项和访问边界？ | 清单、ID、标题、日期、失败记录 |
| 2 语义完整 | 是否读过正文/字幕，而不只是标题和简介？ | 分段笔记、主张、证据、反例、边界 |
| 3 结构完整 | 是否与已有知识去重并连接到主脉络？ | MOC、方法卡、跨来源关系 |
| 4 实践完整 | 是否运行代码、完成作业或用真实任务验证？ | 日志、测试、作品、用户结果、复盘 |
| 5 时效有效 | 当前职位、价格、能力、法规和工具结论是否仍有效？ | 核验日期、版本、下一复查日 |

过去最容易出现的误判是：通过第 1 门就自称完成第 2 门，写了总结就自称通过第 4 门。本库今后必须分别记录。

## 八个个人学习集群

### 集群 0：行动操作系统

**问题**：我现在要解决什么，怎样把阅读变成结果？

入口：`00-personal-knowledge-master-map.md`、18 张核心方法卡、行动闭环。

学习顺序：方向与结果 -> 具体问题 -> 主要矛盾 -> 调查与证据 -> 关键假设 -> 最小闭环 -> 责任与门槛 -> 复盘更新。

完成产物：一条真实行动闭环，不是读书笔记。

### 集群 1：调查、决策与长期方向

**问题**：怎样在复杂条件下判断，而不被经验、权威或短期情绪带走？

来源：毛选、一堂科学决策、人生红点、课程学习地图。

推荐入口：`mao-selected-works-methodology.md` -> `yitang-fupan-effective-notes.md` -> `yitang-section-1869-life-red-dot-notes.md`。

完成产物：问题定义、主要矛盾、支持/反对证据、继续/改变/停止条件。

### 集群 2：LLM 基础与架构

**问题**：LLM 从文本到生成是怎样工作的，组件差异怎样影响能力和成本？

来源：LLMs-from-scratch、Karpathy、Transformer Taxonomy、何恺明、Stanford CS25、QLoRA。

推荐顺序：LLMs-from-scratch 纵向切片 -> Karpathy micrograd/makemore -> Transformer 六层审计 -> 缩放与归纳偏置 -> QLoRA。

完成产物：一个可运行小模型、一张六层模型对照表、一个固定评测集和一次受控实验。

### 集群 3：AI 工程、Agent 与工具系统

**问题**：怎样让模型在真实工作流中可靠完成任务？

来源：WaytoAGI、Latent.Space、OpenClaw、视频学习工作流。

学习主线：任务契约 -> 上下文与检索 -> 工具调用 -> 评测 -> 权限与恢复 -> 人工确认 -> 成本和结果。

完成产物：一个高频、低风险、可验收的端到端 Agent，记录完成率、接管率和严重错误率。

### 集群 4：产品、商业与独立经营

**问题**：怎样从真实需求走到付款、交付、分发和可复用资产？

来源：Levels.io、Jeannen、一堂创业课程、Dwarkesh 商业研究。

学习主线：真实问题 -> 需求证据 -> 手工闭环 -> 首次付款 -> 交付成本 -> 留存/复购 -> 分发 -> 创始人解绑。

完成产物：一次带真实用户、价格、交付成本和停止条件的商业实验。

### 集群 5：研究、表达与信息雷达

**问题**：怎样发现高信号问题、追溯主张、理解分歧并形成可信表达？

来源：Dwarkesh、Truman、Jeannen Media、MIT Bunny。

学习主线：主题账号列表 -> 线索 -> 一手材料 -> 双方最强论证 -> 关键分歧 -> 可观察预测 -> 文章/访谈/报告。

完成产物：一篇包含原始来源、反方和更新条件的研究短文。

### 集群 6：摄影与视觉创作

**问题**：怎样从拍摄意图走到可靠输入、视觉组织、显影、编辑和交付？

来源：Photography Mentor 62 张卡、22 个簇、12 张本机资料摘要。

学习主线：意图与边界 -> 捕获 -> 画面组织 -> 计算显影 -> 题材 -> 编辑表达 -> 管理交付。

完成产物：一个主题组照、接触表、评片记录和可复盘作品集。

### 集群 7：个人知识管理

**问题**：怎样让每次学习可追溯、可搜索、可复习并能改变行动？

来源：总地图、PKM 开源参考架构、五轮迭代、来源完整性审计。

学习主线：捕获 -> 来源状态 -> 综合 -> 方法卡 -> 检索 -> 复习 -> 行动 -> 结果回写。

完成产物：每周清理一次补齐队列，每月淘汰无行动价值的来源和重复卡。

## 默认学习入口

不要从 15,830 条资源的第一条开始顺序阅读。每次学习只执行以下流程：

1. 写下一个当前问题和一个可观察结果。
2. 先打开集群 0 的核心主线，选择一到三张方法卡。
3. 进入一个专题集群，只打开一篇综合稿和最多两个来源条目。
4. 把来源中的事实、作者判断、个人推断和未知项分开。
5. 形成一个作品、实验、决策或真实对话。
6. 结果回写知识卡，并更新来源等级和下一复查日期。
