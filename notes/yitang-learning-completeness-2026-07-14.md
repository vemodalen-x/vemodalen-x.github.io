## 四类 AI 教练

### 新人第一课教学官

完整状态机：身份边界 → 画像/风格 → 热身 → 双三角 → 259/五步法 → 关键假设/低成本验证 → 科学体系 → 覆盖门槛 → 诊断报告。

已验证的关键机制：

- 一轮只问一个核心问题，保留“当前问题”。
- 用户答非所问时先承接有价值内容，再指出跳题并拉回原问题。
- 维护四条主线的覆盖账本，没有用户表达证据就不能标记完成。
- 报告严格区分已掌握证据、薄弱点、待验证假设与训练动作。

### 科学决策搭档

完整状态机：决策与价值 → 分析深度 → 多方案并行画布 → 成本收益补齐 → 主要矛盾 → 纠偏 → 高度扫描 → 停止/继续/加注/切换 → 决策备忘录。

本轮用 AI 商业教练 A/B/C 路径完成实测，并刻意挑战了它对 C 路径的绝对判断。教练能够承认未经确认的前提，把结论降级为假设，并列出会改变排序的新证据。最终报告没有把尚未发生的付费或转化写成事实。

### 第一人生红点架构师

完整状态机：背景 → 关键选择 → 高峰 → 低谷 → 榜样 → 无约束未来 → 极端取舍 → 反证 → 候选报告。

已验证的边界：红点只能是可更新的候选假设，不能锁定身份；需要至少两个替代解释和真实行为实验；不得使用自伤、羞辱或灾难化措辞迫使用户取舍。

### Truman For复盘营

完整状态机：复盘契约 → 起心动念 → 真实使用瞬间 → 投入/价值镜像 → 偏差确认 → 长期后果 → 体系映射 → 直接阻力 → 30 分钟最小体检 → 对象与期限 → 结果回传 → 总结信。

已验证的关键机制与边界：固定主线、一轮一问、场景镜像和结果回传能够把一次咨询变成可复盘实验；本地实现不照搬长篇肯定、身份升级或过早销售转场，并为最坏情形、课程推荐和假门实验增加证据、利益披露与伦理护栏。完整学习报告见 [Truman 复盘教练学习报告](yitang-truman-replay-learning-2026-07-15.html)。
