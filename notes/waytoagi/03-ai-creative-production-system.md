# AI 多模态创作系统

## 核心判断

生成模型解决的是素材生产，不自动解决作品价值。创作结果取决于选题、叙事、审美、参考资产、生成控制、筛选、后期、版权、平台和受众反馈。评价工具时应放进完整链路，而不是只看演示样片。

## 通用生产管线

```text
受众与用途
  → 创意命题与参考研究
  → 脚本 / 分镜 / 乐曲结构 / 角色设定
  → 固定资产与变量表
  → 小样生成和方向选择
  → 批量生成与一致性检查
  → 编辑、声音、排版、调色
  → 版权与事实检查
  → 平台适配与发布
  → 行为反馈与复盘
```

## 图像创作

### 控制维度

- 主体：身份、外形、姿态、服装、关键细节。
- 环境：地点、时间、天气、空间关系。
- 构图：景别、机位、焦段感、主体位置、留白。
- 光线：方向、硬度、色温、对比。
- 视觉语言：材质、色彩、时代、媒介、参考作品。
- 用途：海报、封面、电商、教学图、角色设定等。
- 输出：比例、尺寸、文字区域、透明背景、系列一致性。

参考图往往比更长的文字更能锁定主体和风格。把不变项放在“母模板”，把用途、场景和尺寸放在“子变量”，适合制作电商图、课程视觉和系列内容。

### 质量检查

检查结构与动作是否合理、文字是否准确、产品是否被篡改、人物身份是否一致、画面是否满足真实用途、是否存在未经授权的商标或风格模仿风险。

## 视频创作

视频需要同时控制镜头内运动、镜头之间连续性和整条内容节奏。可先写镜头表：编号、时长、景别、机位、主体动作、环境变化、对白或音效、转场、参考帧。

“真人感”并不等于无限提高分辨率。真实世界包含微小不完美、动作惯性、呼吸、停顿、视线变化、环境噪声和非对称细节。加入真实线索必须服务于叙事，不能变成机械提示词清单。

评价 AI 视频项目时分开记录：创意准备时间、生成次数与费用、可用镜头比例、一致性返工、剪辑和声音时间、发布后的完播与转化。这样才能知道瓶颈是否真的在模型。

## 音乐、语音与数字人

音乐生成要区分旋律、编曲、音色、演唱、混音和版权。语音合成要检查语言、情绪、节奏、可懂度、身份授权和误导风险。数字人还增加口型、表情、身体动作、实时性和披露要求。

使用声音克隆或数字人前应确认本人授权、允许用途、保存期限和撤回方式；面向公众的合成内容应按适用平台和法规进行标识。

## 3D 与空间内容

3D 任务不只看单张渲染图，还要看几何结构、拓扑、材质、UV、骨骼、动画、碰撞、尺度和目标引擎性能。空间计算与 VR 还涉及交互舒适度、帧率、眩晕、设备差异和真实空间安全。

## ComfyUI 与节点工作流

节点式工作流适合把模型、条件控制、参考资产、放大、修复和批量处理显式连接。优点是可重复与可分享，风险是工作流依赖复杂、模型版本变化、显存和素材路径不透明。

保存工作流时同时记录：依赖模型与版本、自定义节点、输入规格、关键参数、显存需求、输出样例和已知失败。不要只保存一张看似漂亮但无法复现的流程图。

## 模型对比模板

| 维度 | 问题 |
|---|---|
| 任务匹配 | 是否覆盖我的真实高频场景 |
| 可控性 | 能否稳定遵守主体、构图、时长和格式 |
| 一致性 | 多图、多镜头、多段声音是否保持身份和风格 |
| 编辑性 | 是否支持局部修改、图层、参考或时间线控制 |
| 成本 | 单个可用成品的总生成与人工成本 |
| 权利 | 输入和输出的授权、训练和商用条款 |
| 可持续性 | 接口、导出、版本和供应商依赖风险 |

## 最小练习

选择一个真实用途，制作三件同系列作品。固定受众、尺寸和主体，只改变一个风格或叙事变量。保留提示、参考、失败样例、成本和人工修改记录，请目标受众盲评，最后形成一张可复用创作卡。
