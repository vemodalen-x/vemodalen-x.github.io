## 一句话结论

**先不要问“应该用 Diffusion 还是 Flow Matching”，先问现实任务能否被清楚地写成条件分布 `p(x|y)`：`y` 是条件、约束或较抽象的信息，`x` 是更具体、更高维、允许多个合理答案的输出。**

生成模型是位于深度神经网络之上的一层抽象：神经网络表示函数，生成模型组织概率分布、目标和采样过程，推理与 Agent 又可把生成模型当作构件。

## 生成问题的四个信号

1. 同一输入可能有多个甚至无限多个有效输出。
2. 有效输出的可信度并不相同，需要概率、能量、偏好或评测函数区分。
3. 训练集中可能不存在部署时要求的那个精确答案。
4. 输出通常比条件更具体、更丰富或维度更高。

第三点不能被偷换成“模型已经证明了真正的分布外泛化”。更稳妥的说法是：模型可从学习到的分布中产生训练集未逐字出现的新样本或新组合；是否属于可靠外推需要单独评测。

## 从实例表征到分布表征

判别模型通常学习从观测到标签或决策边界的映射；生成模型要表示整个数据分布，并从中产生新样本。可把世界理解为潜变量经过成像、语言或物理过程形成观测：姿态、光照、尺度、身份等因素共同决定看到的实例。

深度学习让网络学习实例的表征；深度生成模型进一步让网络学习概率分布的表征。常见做法是从易采样的基础分布出发，将其变换到复杂数据分布。

## 五个基本部件

| 部件 | 要回答的问题 |
| --- | --- |
| 概率问题 | 随机变量、条件和目标分布是什么？ |
| 表征 | 用什么网络、潜变量或向量场表示分布变换？ |
| 目标 | 如何衡量模型分布与数据分布的差异？ |
| 优化 | 如何最小化目标并稳定训练？ |
| 推断/采样 | 部署时如何从条件得到一个或多个样本？ |

困难在于：训练数据通常没有“某个噪声点应该精确对应某个样本”的配对监督。模型需要在分布层面学习映射，而不是记住一张逐点查找表。

## 五类方法的区别

| 方法 | 核心直觉 | 优势 | 主要代价或边界 |
| --- | --- | --- | --- |
| VAE | 把数据分布编码到简单潜分布，再解码回来 | 潜空间和概率解释清楚 | 目标含近似，样本锐度和后验设计会受限制 |
| GAN | 生成器造样本，判别器区分真实与生成 | 可直接产生高质量样本 | 对抗训练不稳定，模式覆盖和显式似然困难 |
| 自回归 | 把联合概率分解为一连串条件概率 | 训练目标直接，适合离散序列 | 采样串行，顺序和误差累积很重要 |
| Diffusion | 逐步加噪，再学习反向去噪 | 训练稳定、覆盖广、条件控制成熟 | 通常需要多步采样，速度和调度影响质量 |
| Flow Matching | 学习把基础分布连续运输到数据分布的向量场 | 几何直觉统一，可用 ODE 采样 | 训练路径、数值积分和可逆条件仍需具体设计 |

并非所有生成模型都能方便计算显式似然；GAN 就常被视为隐式生成模型。因此“生成模型估计概率”是总体建模视角，不是每一种方法都具有的可用接口。

## 用 `p(x|y)` 重写现实任务

| 场景 | 条件 `y` | 输出 `x` | 多解性来自哪里 |
| --- | --- | --- | --- |
| 对话 | 用户问题、历史、约束 | 回答 | 表达、推理路径、取舍不同 |
| 图像/视频 | 文本、草图、参考帧 | 像素或潜变量序列 | 构图、纹理、运动均可变化 |
| 3D | 文本、视图或几何约束 | 形状、材质、场景 | 不完整条件对应多个几何解释 |
| 蛋白质 | 功能、对称性、结构约束 | 蛋白质结构或序列 | 功能目标可由多种结构实现 |
| 开放词汇识别 | 图像和对话条件 | 标签、描述或回答 | 分类粒度和语言表达不是唯一 |
| 机器人 | 视觉、状态、任务 | 动作或轨迹分布 | 同一目标存在多条可行动作路径 |

“治愈癌症”不是一个足够可操作的蛋白质条件。条件如何表示、能否测量、怎样验证，本身就是建模的一部分。

## 判别式还是生成式

“任何问题都能写成生成问题”是一种观察视角，不是所有任务的推荐实现。

- 标签固定、类别少、成本和延迟敏感时，判别模型通常更简单。
- 开放词汇、自然语言输出、多模态对话、多条有效轨迹时，生成建模更自然。
- 可以先用判别基线验证是否真的需要分布级输出，再承担生成模型的采样和评测成本。

## 对个人知识库助手的应用

```text
y = 用户问题 + 检索证据 + 当前项目状态 + 输出格式 + 权限约束
x = 回答 / 笔记 / 方法卡 / 行动计划

有效输出：可以有多个表达和行动方案
不可放松：来源忠实、时间有效、权限安全、可验证
基础分布：模型预训练形成的通用先验
表征：LLM + 检索 + 工具状态
目标：任务质量、证据覆盖、错误率和行动结果
采样：一次回答、候选方案或多代理并行
评测：私有问题集 + 来源核验 + 用户反馈 + 真实结果
```

生成核心的外侧应保留确定性系统：权限、来源记录、索引、版本、审批和回滚不应只依赖模型“自行理解”。

## 批判性边界

- 这是一场高层综述，不包含数学推导、基准对比、算力成本、数据许可和安全评测。
- Flow Matching 的双向变换需要合适的连续流或可逆 ODE 条件，不能理解为任意映射都天然可逆。
- 生成质量、似然和任务效用不是同一指标；漂亮样本不等于覆盖完整或决策正确。
- 分类的生成式改写提高了开放性，也会增加延迟、评测和幻觉风险。
- “生成建模是新的深度学习”是讲者对抽象层级和研究趋势的判断，不是已经完成的技术定理。
