# 视频学习工作流：从媒体到可检索知识

## 一句话结论

我不是把视频“听一遍后凭印象总结”，而是把它当成一个需要取证的数据源：**先确认原始来源和字幕，再用时间戳文本建立内容骨架，用关键帧核对公式、图表与演示，最后把事实、讲者观点、我的推断和适用边界分开写入知识库。**

完整转写稿是中间证据，不是最终知识。最终应留下来源账本、时间轴、概念模型、反例、行动模板和复习问题。

## 决策树

```text
视频 URL
  -> 元数据：标题、作者、上传日期、时长、分集、章节
  -> 追溯一手来源：作者官网 / 官方频道 / 论文 / 代码仓库
  -> 在一手来源再次检查字幕，转载无字幕不等于官方源无字幕
  -> 有人工字幕？优先使用，并抽样听写校验
  -> 只有自动字幕？清洗重复片段，核对专有名词和数字
  -> 完全无字幕？下载最小可用音轨，本地 ASR 生成时间戳文本
  -> 同时获取低码率画面：覆盖抽帧 + 场景变化抽帧
  -> 画面是否含公式、表格、代码或幻灯片？必要时 OCR 和人工复核
  -> 分段归纳：主张 / 证据 / 例子 / 边界 / 未知
  -> 与现有笔记去重，只提升真正新增的方法卡
  -> 重建索引，验证搜索、预览、来源链接和移动端显示
```

## 本机已验证的无字幕链路

验证对象：[Stanford CS25 V4 的 B 站转载](https://www.bilibili.com/video/BV1bm421W7N6/)。B 站接口没有外挂字幕或自动字幕，时长约 77 分钟。

| 环节 | 本次实测 |
| --- | --- |
| 媒体获取 | 复用 `C:\Users\User\Documents\小工具` 中“通用视频下载器”的 `yt-dlp + ffmpeg` 核心 |
| 音轨 | 34 kbps M4A，约 19.6 MB；分块下载约 68 秒 |
| 画面 | 360p AV1，约 45.2 MB；只用于幻灯片和镜头核验 |
| 转写 | Whisper Large v3、PyTorch/Transformers、RTX 4090 24GB |
| 转写结果 | 约 77 分钟音频在 391 秒内得到 178 个时间戳段落、约 65,778 个字符 |
| 视觉核验 | 每四分钟覆盖抽帧生成 20 格联系表；再按概念节点定位原帧 |

这次还验证了两个回退点：

1. B 站大文件单连接曾长时间停滞，改用小音轨优先、Range 分块和断点续传后完成。
2. `faster-whisper` 的 CTranslate2 后端在本机加载 GPU 模型时进程退出；同一模型改由 PyTorch/Transformers 后端成功运行。流水线不能只绑定一个 ASR 后端。

## 每个阶段怎样做

### 1. 来源追溯

转载页只用于发现内容。标题、讲者身份、日期和材料优先回到官方课程页、作者频道、论文或代码仓库。转载日期、活动日期和官方上传日期要分别记录，不能混为一个时间点。

### 2. 字幕与转写

- 人工字幕：可信度最高，但仍抽查数字、公式和专有名词。
- 自动字幕：按时间戳清洗连续重复，保留原始 JSON/VTT 在临时目录。
- 本地 ASR：尽量保留段落起止时间；对人名、模型名、论文名和比例做二次校验。
- 若已经做过本地 ASR，后来发现官方人工字幕：以人工字幕为主证据，将 ASR 用于交叉检查漏段、专名和时间边界。
- 只有听不清或会影响结论的片段才回听原音频，不把低置信文本包装成确定事实。

知识库不保存第三方完整字幕或长篇逐字稿，只保存自己的结构化总结和少量必要短语。

### 3. 画面

先用低频覆盖抽帧确认整段视频的视觉类型，再根据场景变化和文本内容补帧：

- 访谈：通常只需一张身份或场景证据，不保存大量重复头像。
- 讲座：保留总览、关键公式、图表、架构和结论页。
- 演示：保留输入、关键状态和输出三个阶段。
- 代码：优先回到官方仓库；视频截图只用于确认讲者当时的版本和操作。

OCR 是候选文本来源，不是事实来源。公式、表格和小字号内容必须回看原帧。

### 4. 内容账本

每个重要结论按下面五栏记录：

| 栏位 | 问题 |
| --- | --- |
| 主张 | 讲者究竟说了什么？ |
| 证据 | 视频内给了数据、图示、案例还是仅给直觉？ |
| 状态 | 事实、讲者判断、我的推断还是未知？ |
| 边界 | 在什么条件下不成立？有哪些替代解释？ |
| 行动 | 它会改变哪个实验、设计或决策？ |

### 5. 入库与去重

一条视频通常只新增一篇来源综合笔记；只有能反复解决问题、具有边界和下一步动作的内容才提升为方法卡。若只是已有原则的新案例，就在原卡补充来源，不制造同义卡。

## 标准输出

```text
来源审计
一句话结论
时间轴
核心模型或因果链
证据与关键帧
方法之间的区别
讲者观点与事实的分界
反例、风险和时效边界
与现有知识库的连接
一个可执行模板
5-8 个主动回忆问题
```

## 四层完整性验收

| 层 | 必须回答的问题 | 未满足时的状态 |
| --- | --- | --- |
| 集合 | 这是单个视频还是频道？条目总数和抓取日期是否固定？ | 只能称单条学习或目录快照 |
| 章节 | 时间轴是否从开始连续覆盖到结束，问答和片尾是否被遗漏？ | 不能称语义级完整 |
| 证据 | 字幕类型、ASR 后端、关键帧和一手资料是否记录？ | 只能称印象总结 |
| 知识 | 主张、证据、边界、应用、复习和检索是否都通过？ | 只能称处理完成，不能称已经学会 |

对频道或播放列表，“抽取了全部标题”只通过集合层；只有每条正文或字幕都经过章节、证据和知识三层，才可声称全量学习。

## 我能够和不能够怎样“看视频”

我可以读取公开元数据、字幕、音频转写和抽取的画面，并在时间轴上交叉核对；这相当于把视频拆成可审计的文本与视觉证据。我不会像人一样持续体验整段视听氛围，也可能遗漏语气、笑点、板书过程和短暂画面。因此，关键主张需要字幕、原声、幻灯片和一手资料中的至少两类证据支持；没有支持时明确标为推断或待核验。

## 验收清单

- [ ] URL 已去除不必要追踪参数，来源层级清楚。
- [ ] 若来源属于频道或合集，条目总数、唯一 ID、抓取日期和失败项已记录。
- [ ] 日期区分活动、官方上传和转载。
- [ ] 字幕类型与 ASR 后端已记录。
- [ ] 转载无字幕时已经回到官方源再次检查人工字幕。
- [ ] 时间轴从 `00:00` 连续到结束，问答没有被一句话带过。
- [ ] 专有名词、数字和公式已抽查。
- [ ] 关键帧确实补充信息，而非装饰。
- [ ] 事实、讲者预测和个人推断已分开。
- [ ] 没有把完整第三方文字稿复制进知识库。
- [ ] 新笔记与现有卡片完成去重。
- [ ] 搜索能用讲者、主题和方法词找到笔记。
