## 证据分级

1. **嘉宾观点**：只能写成“某嘉宾在某日期主张”，不能自动升级为事实。
2. **主持人综合判断**：跨资料研究后的解释模型，仍需检验前提与反例。
3. **作者推测**：保留原文的认知状态，例如“高度推测”或主观概率。
4. **带日期预测**：记录日期、概率、操作化里程碑、关键分歧和更新条件。
5. **第一方经营数据**：受众调查、增长渠道和商业套餐均为平台自报，需要标记抽样偏差。
6. **外部可核验事实**：优先回到论文、公司披露、政策文件或原始数据交叉验证。

转录稿必须保留说话人。引用一个结论时，同时记录“谁说、何时说、基于什么、什么会推翻它”。

## 跨内容研究模型

### 1. 问题优先研究卡

- 要支持的决策是什么？
- 唯一核心问题是什么？
- 为什么它在当前时间点重要？
- 哪个关键分歧最可能改变结论？
- 交付物、字数、时间盒和证据标准是什么？

题目应足够重要、足够具体、能在限制内形成判断。先固定问题，避免检索过程不断漂移。

### 2. 访谈研究栈

1. 按研究价值选择专家，不按名气排序。
2. 阅读嘉宾作品、旧访谈和批评意见。
3. 与同领域其他人交叉核对问题和盲区。
4. 形成访谈课程：基础、关键分歧、反例、可观察预测。
5. 访谈后按说话人保存主张，并回查关键数据的原始来源。

### 3. 关键分歧图

| 字段 | 内容 |
| --- | --- |
| 命题 | 双方究竟在争什么 |
| Believer 最强论证 | 支持方在最佳版本下的因果链 |
| Skeptic 最强论证 | 反对方在最佳版本下的因果链 |
| Crux | 哪个事实不同会使双方改变看法 |
| 可观察更新 | 未来 30/90/365 天能看到什么 |
| 当前证据缺口 | 哪一环只有类比、访谈或推测 |

### 4. 预测更新账本

每条预测保存：创建日期、预测窗口、操作化里程碑、主观概率、关键分歧、反证、下一复盘日和实际结果。预测必须可判定，不能写成“AI 会越来越强”。

### 5. 能力到业务权力栈

> 模型能力 -> 工具可用性 -> 系统可靠性 -> 数据与访问权限 -> 人类信任 -> 决策授权 -> 资源控制 -> 组织协调 -> 可归责结果

Demo 只验证靠前层。企业价值通常在整条链能闭环后才出现。

### 6. 验证拓扑

- **可验证**：结果对错是否有清晰判据。
- **可重复试错**：环境能否低成本重置并大量并行。
- **反馈延迟**：结果需要秒、天、月还是年才能判断。
- **代理风险**：可测指标是否会替代真正目标。
- **部署数据**：上线行为能否合法、可控地形成下一轮学习材料。

对于销售、管理、科研和政策等长周期任务，不应用短周期 benchmark 直接外推业务结果。

### 7. AI 物理约束栈

模型与产品判断同时检查：计算、内存与带宽、网络、功耗与散热、机房与电网、晶圆制造与设备、供应链交期、资本和监管。每项注明依赖方、替代性、时间尺度和数据日期。

### 8. 自动化公司的稀缺性迁移

这是情景分析，不是确定预测：当部分认知劳动可复制时，价值可能向专有数据、算力与能源、分发、客户信任、责任承担、品牌、品味和现实资源迁移。商业教练要追问“哪项资产在竞争加剧后仍稀缺”。

### 9. 作品样本式人才发现

- 用真实、边界清晰、付费的短任务替代抽象简历筛选。
- 评价陌生领域上手速度、关键变量识别、反驳与综合能力。
- 事先公布时限、格式、评分锚点、知识产权和报酬。
- 避免用大规模无偿方案征集转嫁企业研究成本。

### 10. 高价值受众商业化

受众质量与到达规模分开：职位、预算权、主题相关性、地区和购买时点比播放量更接近商业价值。合作产品应记录归因窗口、合格线索、续约、受众疲劳和抽样偏差。

## 图像与转录证据账本

| 信息类型 | 可以支持 | 不能支持 |
| --- | --- | --- |
| 封面与人物照片 | 内容身份、嘉宾和叙事定位 | 观点正确性、专业结论 |
| 时间戳与章节 | 论题位置、说话顺序、回查入口 | 嘉宾主张已经过事实核验 |
| 转录文本 | 某人在某时说过什么 | 自动转录绝对准确、主持人认同嘉宾 |
| 概念图 | 变量和因果假设的组织方式 | 因果关系已被证实 |
| 时间线与概率 | 某日期的预测状态 | 预测已经兑现或仍然有效 |
| 算力与供应链图 | 物理依赖和瓶颈位置 | 数量级、价格或交期永远不变 |
| 受众与增长图 | 第一方样本在特定时间的自报结果 | 全体受众、因果归因或审计级收入 |

## 对 Business Tutor Agent 的改进

1. 深度研究先生成问题卡，不直接堆资料。
2. 所有访谈结论增加说话人、日期与证据类型。
3. 对争议问题生成双方最强版本、关键分歧和更新证据。
4. 对 AI 时间线和市场预测生成可复盘的预测账本。
5. 对 AI 产品把能力、可靠性、权限、信任、授权和责任分层。
6. 对训练与 Agent 任务检查可验证性、可重复试错性、反馈延迟和代理风险。
7. 对算力密集业务增加物理约束、供应链和资本时间尺度。
8. 对自动化公司只输出情景树，不把作者推测写成确定趋势。
9. 对专家招聘与研究岗位优先设计付费作品样本和明确评分锚点。
10. 对内容商业化同时检查受众质量、预算权、归因和第一方调查偏差。
