# 个人知识库总地图：从问题到复盘的核心主线

## 一句话结论

这套知识库真正反复回答的是同一个问题：**怎样把模糊愿望变成一个有证据、可验收、能复盘的真实结果，并让每次行动留下可复用资产。**

毛选提供调查、矛盾、实践、阶段与执行骨架；一堂提供假设、商业关口、科学决策和长期方向；Levels.io 与 Jeannen 提供发布、收费、分发、现金流和独立资产；WaytoAGI 与 Latent.Space 提供 AI 任务、评测、检索、智能体和治理；Dwarkesh 与 Truman 补充研究、论证、表达和组织复盘；摄影与职业资料是这些方法的应用分支。

原来的问题不是资料不够，而是同一个原则散落在不同作者、案例和文件中。此次重构不删除来源，而是增加一层可以直接调用的“核心主线”。

## 三层结构

```text
来源档案层：原文线索、公开目录、课程记录、案例、旧库索引
       ↓ 回答“证据从哪里来，原语境是什么”
专题综合层：毛选 / 商业 / 独立产品 / AI 工程 / 摄影 / PKM
       ↓ 回答“这个领域有哪些特殊约束”
核心主线层：18 张跨来源归并卡
       ↓ 回答“我现在应该如何判断和行动”
行动与复盘层：问题、证据、行动、门槛、结果、方法更新
```

使用原则：日常先从核心主线进入；遇到领域问题再打开专题综合；需要核验、引用或理解边界时才下钻来源档案。

## 核心脉络

```text
长期方向与底线
  → 具体对象、场景、阶段和结果
  → 当前主要矛盾
  → 调查用户、行为、替代方案与历史条件
  → 建立事实、推断、未知和来源账本
  → 选择会改变决策的关键假设
  → 预先定义评测、反证与信号强度
  → 跑通最小端到端闭环
  → 写清任务契约、工具边界与人机权限
  → 绑定负责人、期限、验收和复盘点
  → 按继续、改变、停止、扩大门槛决策
  → 连接付款、交付成本、分发和信任
  → 用作品证明学习，让项目留下复利资产
  → 用真实结果更新方法、评测集和知识库
  → 由人保留目标、取舍、安全与最终责任
```

## 18 张归并后的核心卡

### 阶段一：方向与问题

1. **方向层级**：区分长期方向、当前结果和不可击穿的底线。
2. **具体问题**：写清对象、场景、阶段、期限和验收结果。
3. **主要矛盾**：找到当前最限制结果、改变后能带动全局的瓶颈。

### 阶段二：调查与证据

4. **调查用户**：观察真实行为、替代方案、成本和历史条件。
5. **证据账本**：保留来源、日期、口径和认知状态；分开事实、推断与未知。
6. **关键假设**：只验证会改变决策的假设，并寻找反证和替代解释。
7. **评测与信号**：先定义验收集，再区分关注、使用、付款、留存等证据强度。

### 阶段三：实验与工程

8. **最小闭环**：用最短完整链路让一位真实对象获得结果。
9. **任务契约**：明确输入、上下文、输出、约束、质量和失败处理后再选工具。
10. **人机工作流**：让 AI 可观察、可恢复、有最小权限和人工确认点。

### 阶段四：执行与动态决策

11. **责任闭环**：行动绑定唯一负责人、期限、产物、验收和复盘点。
12. **决策门槛**：投入前写清继续、改变、停止与扩大条件。

### 阶段五：商业、表达与资产

13. **商业证据**：尽早连接付款、交付成本、留存、复购与现金回收。
14. **分发与信任**：产品价值和价值被理解属于同一条交付链。
15. **输出式学习**：用真实问题和可评价作品倒推资料与练习。
16. **复利资产**：让每次项目留下案例、代码、模板、SOP、渠道或客户证据。

### 阶段六：复盘与治理

17. **知识更新**：用结果和误判修改方法、评测集、SOP 与停止规则。
18. **人类责任**：AI 扩大探索，人保留目标、取舍、治理和最终责任。

完整卡片位于 `knowledge/core-method-kb.js`，并已进入方法助手和间隔复习。

主入口：本总地图、PKM 参考架构和迭代记录。独有问题是来源、综合、行动三层分离，渐进式摘要、检索反馈、间隔复习和版本维护。

## 一条日常使用路线

1. 写清当前要改变的结果、期限和底线。
2. 用核心卡 2-3 找具体问题和主要矛盾。
3. 搜索最多三份精选笔记，建立事实、推断和未知项。
4. 选择一个关键假设，写支持、反对与推翻标准。
5. 设计 1-7 天可完成的最小闭环和验收指标。
6. 明确负责人、成本、权限、停止条件与复盘日期。
7. 执行并记录真实行为、付款、质量、意外与反证。
8. 复盘后更新行动、方法卡、评测集或知识地图。

## 去重规则

新增材料进入知识库时按以下顺序处理：

1. **先保存来源**：记录作者、日期、链接、证据类型与访问边界。
2. **再查核心主线**：若只是已有原则的新案例，不新增核心卡，只给原卡补来源或反例。
3. **检查领域差异**：只有出现新的适用条件、失败模式、指标或执行协议，才进入专题卡。
4. **产生行动才提升**：资料必须能改变判断、生成实验或修正方法，才从目录层提升到精选层。
5. **保留反证**：与现有结论冲突的高质量材料优先记录，不以“保持整洁”为由删除。

## 维护节奏

- 每日：只捕捉问题、来源和下一步，不在收集时过度分类。
- 每周：合并重复笔记，完成 10 张核心/专题卡复习，关闭或更新到期行动。
- 每月：检查工具、模型、法规和平台资料的时效；把已验证结论提升为方法，把失效结论降级或标注。
- 每季度：检查长期方向、主要矛盾、在建项目和复利资产，归档没有行动价值的中间记录。
