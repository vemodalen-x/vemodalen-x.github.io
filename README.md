# Photography Mentor

Photography Mentor 是一个本地优先的摄影学习 Web 应用。它把计算摄影、摄影美学、前期拍摄、后期处理和评片方法整理成可追溯知识卡，并用主动回忆、刻意练习、作品证据和间隔复习形成学习闭环。

## 产品能力

- 62 张公开来源摘要卡、7 个学习阶段、22 个知识节点。
- Focus、Map、Studio、Library 四个任务空间。
- 知识图谱搜索、掌握度过滤、节点检查器和一键开课。
- 浏览器内照片亮度、对比度、饱和度、清晰度、高光和阴影诊断。
- Before/After 练习证据、练习日志、学习档案和复习队列。
- SYBJ 官方微信登录跳转，以及用户自有课程摘要的本地导入。
- 学习档案、计划、掌握度、练习和摘要的一键导出、恢复与删除。
- 无服务器账号、无广告追踪、无运行时 CDN，支持安装与离线使用。

## 启动

需要通过 HTTP 提供页面，不能直接双击 HTML 使用 Service Worker。

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8000/`。

## 验证

```powershell
npm test
```

`npm test` 会验证知识卡、分类结构、页面引用、离线缓存和公开发行边界。重新生成发行清单使用 `npm run manifest`。

## 数据边界

用户档案、草稿、复习状态、练习日志和手动导入摘要只保存在当前浏览器。照片像素只在当前标签页内处理，不写入浏览器持久存储。应用不会读取微信凭据、Cookie 或登录后的 SYBJ 页面。

公开包不包含本机书籍、私人资料、访问受限内容、凭据、截图或旧仓库历史。知识库只保存摘要和来源链接，不重新发布教程或书籍全文。
