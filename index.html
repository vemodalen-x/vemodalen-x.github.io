Engineering taste

  • Start from the workflow. A useful AI system starts with the operational problem, not the model demo.
  • Deployment is part of modeling. Architecture, I/O, quantization strategy, runtime constraints, and debug tooling should be designed together.
  • Quality lives in edge cases. Camera quality is won in difficult lighting, motion, occlusion, hair boundaries, foreground objects, and device variation.
  • Agents need eval, not vibes. Multimodal decisions should be constrained, compared, reproduced, and debugged.
  • Public work should be safe by design. I describe reusable engineering judgment without exposing customer names, internal paths, model artifacts, logs, or private thresholds.
