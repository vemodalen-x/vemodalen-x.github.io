Selected Work

Case studies in deployable vision and multimodal AI.

These notes avoid internal names and volume-based proof. Each case keeps the reusable part: the problem, the approach, and the deployment judgment it represents for forward-deployed AI work.

See the technical leadership map

Training-to-deployment foundation

A stable delivery path for the parts of vision model development that often fragment: training, data, quantization, export, validation, and deployment debugging.

Problem

On-device vision models often break across training, conversion, quantization, and inference. The closer a model gets to production, the more details decide whether it ships.

Approach

Put training configuration, data interfaces, quantization paths, and export validation into one workflow so model development starts with deployment constraints in mind.

Signal

This represents how I treat a model not as a standalone artifact, but as a component in a deployed system.

Real-time composition engine

Composition guidance for live preview: understanding subjects, motion, and frame relationships on-device, then turning that into stable interaction.

Problem

Camera interaction cannot rely on single-frame recognition alone. Subjects move, the frame shakes, and guidance must not jump around or feel unpredictable.

Approach

Combine lightweight detection, optical-flow tracking, and state machines to turn perception into interpretable, debuggable, real-time guidance.

Signal

This represents my ability to design across algorithms, system state, and user experience.

Depth-aware bokeh

Combining monocular depth, portrait segmentation, and rendering to support real camera bokeh experiences.

Problem

Bokeh is not just background blur. Users notice hair, boundaries, multi-person relationships, highlight texture, and foreground/background layering.

Approach

Use depth and segmentation to model spatial relationships, rendering to define the visual feel, and edge-case tuning to handle device variation.

Signal

This represents my understanding of the gap between model output and the final image in computational photography.

Multimodal composition agent

Using VLM/LLM reasoning for visual composition while adding structure so outputs can be evaluated, debugged, and improved.

Problem

Composition has aesthetic and semantic components, so pure rules are limited. But model outputs can be unstable, hard to reproduce, and expensive.

Approach

Split the agent into perception, candidate generation, selection, and output stages, require structured results, and keep hooks for evaluation and retry.

Signal

This represents my attitude toward agents: deployable workflow components with constraints, evaluation, and handoff paths.

GPU rendering and portrait enhancement

Combining deep models with OpenGL/GLSL rendering pipelines to turn model signals into controllable visual effects.

Problem

The hard part of visual enhancement is often not one model, but the coordination between model outputs, rendering parameters, performance budget, and final appearance.

Approach

Connect detection, depth, segmentation, matting, rendering, and accelerated inference while keeping module boundaries debuggable and modular.

Signal

This represents my ability to integrate models, graphics rendering, and system deployment.
