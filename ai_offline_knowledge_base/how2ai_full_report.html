1. 课程定位

MAS.S60 How2AI Spring 2025 面向的是“如何做 AI 研究与系统构建”这个问题，而不是只讲单一模型或单一应用。课程从 AI research workflow、数据和表示学习切入，逐步进入模型架构、多模态学习、大模型、现代生成模型、交互式 agent 和 Human-AI interaction。它的技术范围覆盖 AI/CV/AIGC 工程师最常见的完整链路：数据与目标定义、模型结构选择、预训练/微调/部署、多模态对齐与融合、生成模型路线、偏好学习与安全交互。

适合读者包括：已经能训练/微调模型但希望建立论文脉络的 AI engineer；做 CV、VLM、AIGC 或 agent 的工程师；需要快速理解多模态与 foundation model 技术演进的研究型产品/算法负责人。课程不适合作为零基础机器学习入门，它默认读者愿意读论文、做实验，并能把工具链和研究问题连接起来。

2. 全局知识地图

2.1 AI research foundations

  • 覆盖讲次：Week 1, Week 2 practical tools
  • 核心问题：把 AI 研究拆成问题定义、文献阅读、实验设计、工具链和 debug 闭环。
  • 关键技术：论文阅读与写作、实验假设、PyTorch、Hugging Face、训练诊断、研究项目构思。
  • 与前后模块关系：为后续模型、数据和多模态主题提供研究方法与工程执行底座。
  • 工程实践价值：工程师可以把它转化为实验记录模板、训练检查清单和模型迭代流程。

2.2 Data, representation, and generalization

  • 覆盖讲次：Week 2, Week 4 Discussion 1
  • 核心问题：数据模态、结构、训练目标和规模如何决定表示质量与泛化行为。
  • 关键技术：representation learning、self-supervision、generalization、double descent、grokking、data quality。
  • 与前后模块关系：承接研究方法，向模型架构和 foundation model 的可扩展训练过渡。
  • 工程实践价值：直接影响数据配比、预训练目标、评测集设计和泛化风险控制。

2.3 Model architectures

  • 覆盖讲次：Week 4, Week 5 Discussion 2
  • 核心问题：不同数据结构需要什么归纳偏置，以及 Transformer 为什么成为通用架构。
  • 关键技术：CNN、RNN/attention、Transformer、ViT、Deep Sets、GNN/GAT、GraphSAGE、ConvNeXt。
  • 与前后模块关系：从单模态结构先验过渡到多模态对齐与大模型统一建模。
  • 工程实践价值：帮助工程师选择视觉、序列、集合、图和混合模态输入的模型骨架。

2.4 Multimodal learning

  • 覆盖讲次：Week 5-7, Discussion 3-4
  • 核心问题：异构模态如何建立联系、对齐语义、显式交互，并在模态间迁移能力。
  • 关键技术：contrastive alignment、image-text relation、fusion、cross-modal interaction、translation、transfer。
  • 与前后模块关系：以 representation 和 architecture 为基础，连接到 multimodal LLM 的预训练与推理。
  • 工程实践价值：对 CV/AIGC 工程尤其关键，覆盖图文检索、视觉问答、医学/机器人/生成式多模态系统。

2.5 Large foundation models

  • 覆盖讲次：Week 9, Week 11, Discussion 5-6
  • 核心问题：规模化预训练、指令调优、参数高效适配、量化和多模态 LLM 扩展如何协同。
  • 关键技术：scaling laws、instruction tuning、LoRA、quantization、MoE、MAE、LLaVA、any-to-any MLLM。
  • 与前后模块关系：把多模态学习的对齐/融合问题放入大模型训练、适配和部署框架中。
  • 工程实践价值：最贴近 production model design：数据配比、adapter 设计、推理成本、开放模型追赶商业模型。

2.6 Generative models

  • 覆盖讲次：Week 12, Week 13 Discussion 7
  • 核心问题：现代生成模型如何从 diffusion 扩展到 flow matching、rectified flow 与媒体 foundation models。
  • 关键技术：Diffusion Transformer、latent flow matching、rectified flow、video/media generation、conditional generation。
  • 与前后模块关系：与 multimodal foundation model 合流，面向图像、视频、音乐、动作等 AIGC 任务。
  • 工程实践价值：为 AIGC 工程提供采样效率、可控生成、多模态生成管线和高分辨率合成的技术路线。

2.7 Interactive agents and Human-AI interaction

  • 覆盖讲次：Week 14-15
  • 核心问题：模型如何通过偏好、反馈、环境交互和人机协作形成可控、可靠的智能体能力。
  • 关键技术：RLHF、DPO、reasoning RL、reward design、VLA、multimodal agents、human-in-the-loop、safety。
  • 与前后模块关系：把 static model 推向交互式 agent，要求生成、感知、推理和安全机制一起设计。
  • 工程实践价值：适合做 AI agent、机器人、教育辅导、Web task agent 和安全评测方向的工程落地。

5. 技术主线分析

5.1 从 representation learning 到 foundation models

课程先用 representation learning、data structure、generalization 建立底层问题：模型不是凭空泛化，而是在数据分布、训练目标和归纳偏置共同作用下学到可迁移表示。随后通过 scaling laws、instruction tuning、LoRA、quantization、MoE 等资料，把“学到好表示”推进到“在给定 compute/data/latency 约束下训练和部署可复用 foundation model”。这条线对工程最重要的启发是：先明确目标分布和评测，再决定预训练/微调/检索/adapter，而不是直接套最新模型。

5.2 从单模态模型到 multimodal alignment / fusion / transfer

单模态部分强调结构先验：图像有局部性，序列有时序依赖，集合需要置换不变性，图需要邻接结构。多模态部分则把问题改写为三层：alignment 解决共享语义空间，fusion 解决交互与互补信息，transfer 解决能力跨模态迁移。工程上，这对应三类系统设计：图文检索/CLIP 类系统优先 alignment；VQA、情感分析、机器人感知等任务需要 interaction/fusion；医学、embodied AI、理解-生成一体化系统更依赖 transfer。

5.3 从 Transformer 到 multimodal LLM

Transformer 的关键作用不是只替代 RNN/CNN，而是把不同数据转成 token 后统一处理。ViT 把图像 patch 化，Multimodal Transformer 处理未对齐多模态序列，LLaVA/PaLI/Kosmos/Chameleon/MM1/NExT-GPT 等资料则把视觉、文本、生成、grounding 和 any-to-any 输入输出纳入 LLM 框架。这里的核心工程问题是模态接入位置：early fusion 能提供更强统一建模但训练更贵；adapter/projector 路线更易复用 LLM；grounding 和交互任务要求评测超出静态 caption 或 VQA。

5.4 从 diffusion 到 flow matching / generative modeling

生成模型主线从 Diffusion Transformer 和可控生成进入 flow matching、latent flow matching、rectified flow。课程把它放在 large models 之后，是因为现代 AIGC 不再只是单个图像生成模型，而是媒体 foundation model：图像、视频、动作、音乐等模态共享生成建模、条件控制和 scaling 问题。工程师需要关注的不是“diffusion 或 flow matching 谁赢”，而是训练稳定性、采样步数、条件控制、分辨率扩展、多模态一致性和服务成本。

5.5 从 static model 到 interactive agent / human-in-the-loop AI

课程最后转向 interactive agents、reasoning、human-in-the-loop 和 safety，说明模型部署后会进入反馈环境。RLHF、DPO、reward function failures、DeepSeek-R1、VideoWebArena、OpenVLA、Human-AI guidelines 等资料共同指向一个判断：agent 系统不是单纯更强的 base model，而是模型、环境、奖励/偏好、工具调用、用户交互和安全边界的组合系统。

6. 面向工程实践的启发

6.1 最值得优先学的主题

  • AI Engineer：Practical AI tools、Large foundation models、LoRA/quantization、interactive agents and preference optimization。它们最直接影响训练成本、调试效率和部署方案。
  • CV Engineer：Model architectures、ViT/MAE、Geometric Deep Learning、multimodal alignment、CLIP/VLM 路线。它们决定视觉 backbone、预训练目标和图文迁移能力。
  • AIGC Engineer：Modern generative models、Diffusion Transformer、Flow Matching、Movie Gen、multimodal LLM with generation。它们对应图像/视频/动作/音乐生成管线和可控生成策略。

6.2 对 production model design 有直接价值的资料

  • A Recipe for Training Neural Networks：可转成训练 debug checklist。
  • Attention Is All You Need、ViT、MAE：帮助理解当前视觉和多模态 backbone 的 token 化设计。
  • Training Compute-Optimal Large Language Models：直接影响 data/compute/model size 配比。
  • LoRA、Quantization、MoE visual guide：对应微调成本、推理成本和容量扩展。
  • Quantifying & Modeling Multimodal Interactions、Does my multimodal model learn cross-modal interactions：帮助设计多模态 ablation 与评测。
  • DPO、Deep reinforcement learning from human preferences、Faulty reward functions：对应 alignment、偏好优化和 agent 安全风险。

6.3 偏 research taste / idea generation 的内容

Platonic Representation Hypothesis、Understanding the Emergence of Multimodal Representation Alignment、Does equivariance matter at scale、Unintended Impacts of LLM Alignment on Global Representation、Compositional Generative Modeling 等资料更适合用来生成研究问题。它们未必马上变成产品功能，但能帮助判断为什么某些模型行为出现、哪些评测可能失真、哪些假设值得做 ablation。

6.4 可转化为实验项目的方向

  • 小规模 CLIP/contrastive alignment：比较 view 设计、数据噪声和 hard negatives 对检索性能的影响。
  • 多模态 fusion ablation：验证模型是否真正使用跨模态交互，而不是依赖单模态 shortcut。
  • LoRA vs full fine-tuning vs quantized fine-tuning：在固定 GPU 预算下比较质量、速度和显存。
  • MAE/ViT 小规模复现：比较 mask ratio、patch size 和下游线性探测。
  • Diffusion vs flow matching toy benchmark：比较采样步数、FID/CLIPScore 或任务特定指标。
  • DPO/RLHF toy alignment：用偏好数据比较 reward model 与 direct preference objective。
  • Multimodal agent evaluation：参考 VideoWebArena 思路，构造视频理解或网页操作任务集。

7.3 适合做 paper reproduction 的候选题

  • ViT：小数据集上 patch size、augmentation、预训练/从零训练对比。
  • CLIP / contrastive learning：图文或图像增强 view 的对比学习复现。
  • Deep Sets / GAT：在集合或图数据上复现结构归纳偏置效果。
  • LoRA：固定 GPU 预算下对比不同 rank、target module 和量化设置。
  • MAE：复现 mask ratio 对表示质量的影响。
  • DiT 或 flow matching toy model：比较采样效率和生成质量。
  • DPO：在小型偏好数据上比较 SFT 与 DPO 的行为差异。

7.4 适合做 survey / tech report 的候选题

  • Multimodal alignment 从 CLIP 到 multimodal LLM 的技术演进。
  • Fusion vs alignment vs translation：多模态迁移系统设计取舍。
  • Multimodal LLM 架构：projector/adapter、early fusion、any-to-any 的成本与能力边界。
  • Diffusion、rectified flow 与 flow matching 的统一视角和工程差异。
  • Preference optimization 从 RLHF 到 DPO/Reasoning RL 的路线。
  • Human-in-the-loop AI 的评测、反馈和安全机制。
