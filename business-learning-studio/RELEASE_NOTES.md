# Business Learning Studio Commercial v1.0.0

This is the first complete commercial release of the privacy-first business learning workspace.

## Included

- Learning plan, practice, feedback and mastery workflows
- 32 original business knowledge cards across eight stages
- Five-gate local business coach and live decision canvas
- Offline cache and local-only runtime dependencies
- User-controlled JSON export and reset

## Privacy and provenance

The release contains no raster screenshots, local file metadata, account data, browser-cache files, paid-course transcripts or copied long-form notes. The attached checksum file can be used to verify the downloadable package.

## Verification

The source was regenerated, contract-tested, privacy-audited and packaged from an explicit allowlist before tagging.
