System shape

A small provider protocol keeps model adapters outside the workflow core. The router records every attempt, retries expected transient failures, falls back on permanent or contract failures, validates structured outputs, and forces human review below the request confidence threshold.

request -> route(primary) -> attempt -> transient failure
        -> route(fallback) -> validate contract
        -> confidence gate -> accepted output + trace
